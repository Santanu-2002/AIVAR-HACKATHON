1. AIVAR — Autonomous Web Testing Agent

Hackathon Project | React.js, Node.js, Express.js, MongoDB, Playwright, LLM APIs

AIVAR is an autonomous web application testing platform designed to take a web application URL and automate the testing lifecycle.

Core workflow

Accept a web application URL as the primary input.

Planner agent explores the application and creates a structured test plan.

Generator agent converts the plan into executable Playwright tests and validates selectors/assertions.

Test execution identifies failures.

Healer agent analyzes failed tests and repairs broken selectors or flows.

Orchestrator evaluates coverage and coordinates re-planning or healing.

Final reports summarize scenarios, results, repairs, coverage gaps, and risks.

My technical focus

React-based frontend and dashboard experience.

Node.js/Express backend APIs.

MongoDB data persistence.

Authentication and protected application flows.

Playwright-based browser automation.

Integration with LLM APIs for agentic test planning/generation/healing.

Note: The exact implementation status of individual agent capabilities can vary during the hackathon; this README describes the intended product architecture.
